# DKV ITB

> **Website Profil Program Studi Desain Komunikasi Visual**

Website profil **Desain Komunikasi Visual (DKV) ITB** yang dirancang sebagai media informasi digital dengan pendekatan visual yang modern, responsif, dan berorientasi pada pengalaman pengguna.

Website ini menyajikan informasi program studi melalui beberapa halaman utama, mulai dari profil, galeri, tim, FAQ, hingga informasi kontak.

---

## Overview

Project ini merupakan implementasi website profil berbasis **frontend development** menggunakan teknologi web fundamental.

Fokus utama project:

* Modern & clean visual interface
* Responsive web layout
* Structured information architecture
* Interactive user interface
* Consistent typography & visual hierarchy
* Optimized presentation of visual content

## Design Direction

Website menggunakan pendekatan visual yang menyesuaikan karakter **Desain Komunikasi Visual**.

### Visual Principles

**Typography**

Menggunakan typography yang kuat untuk membangun hierarchy antara heading, subheading, dan body text.

**Layout**

Menggunakan layout yang fleksibel dengan whitespace yang cukup agar informasi tetap mudah dipahami.

**Visual Content**

Elemen visual digunakan sebagai bagian penting dari storytelling website, bukan hanya sebagai dekorasi.

**Interaction**

JavaScript digunakan untuk mendukung interaksi pada halaman dan memberikan pengalaman browsing yang lebih dinamis.

**Responsive**

Layout dirancang agar dapat beradaptasi pada berbagai ukuran layar, mulai dari desktop hingga perangkat mobile.

## Features

### Responsive Layout

Website dapat menyesuaikan tampilan berdasarkan ukuran viewport sehingga konten tetap nyaman digunakan pada berbagai perangkat.

### Multi-Page Navigation

Website memiliki beberapa halaman yang saling terhubung untuk memisahkan informasi berdasarkan kategori.

### Visual Gallery

Halaman galeri digunakan untuk menampilkan konten visual secara lebih terstruktur.

### FAQ Section

Halaman FAQ menyediakan ruang untuk menyajikan pertanyaan dan informasi yang sering dibutuhkan pengunjung.

### Contact Page

Halaman kontak menyediakan informasi yang dapat digunakan pengunjung untuk mendapatkan informasi lebih lanjut.

## Getting Started

### Requirements

Tidak membutuhkan framework atau dependency khusus.

Yang diperlukan:

* Web Browser modern
* Visual Studio Code *(optional)*
* Live Server *(optional)*

### Run Locally

Clone repository:

```bash
git clone https://github.com/Janestreett/dkv-itb.git
```

Masuk ke directory project:

```bash
cd dkv-itb
```

Kemudian buka:

```text
index.html
```

atau gunakan **Live Server** pada Visual Studio Code untuk menjalankan project secara lokal.

## Responsive Breakpoints

Pengembangan responsive design mempertimbangkan beberapa kondisi viewport:

```text
Desktop
   ↓
Laptop
   ↓
Tablet
   ↓
Mobile
```

Setiap komponen perlu tetap memiliki hierarchy, spacing, dan readability yang baik ketika ukuran layar berubah.
